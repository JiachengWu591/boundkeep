## 2. 改了什么

只改了 `audit/send_gate.py` 里把主目录写成 `~` 的那一步（`_Places.word`）。词、命令全文、展开过变量的路径原文都经过它。`paths` 按路径的键换，本来就对，没动。

- **认的写法**（`_home_forms`）：
  - 主目录是 `C:\Users\<名字>` 时，认 `C:\Users\<名字>`、`C:/Users/<名字>`、`C:\\Users\\<名字>`、`/c/Users/<名字>`、`/mnt/c/Users/<名字>`、`/cygdrive/c/Users/<名字>`，长的先试。
  - 其他主目录（POSIX）只认原样，两种斜杠都认。
  - 主目录短于 4 个字符时，一种都不认。这和原来一样，`C:\`、`/` 不换。
- **大小写**（`_caseless`）：字母不分大小写，只认单个字符之间的大小写对应。`ſ`、开尔文符号这类只有 Unicode 折叠才相等的写法，算另一个名字。`Jürgen` 和 `JÜRGEN` 相等，中文名字原样匹配。
- **后面的边界**：后面必须是文字末尾、空白，或 `\ / ' " `` ` `` ; | & ( ) < > , : { } [ ]` 之一。所以 `<主目录>x`、`<主目录>2`、`<主目录>.CORP`、`<主目录>_old`、`<主目录>$suffix`、`<主目录>*` 都不换。
- **前面的边界**：
  - 盘符开头的写法：前一个字符不能是字母、数字、下划线。
  - 斜杠开头的写法：前一个字符不能是字母、数字、下划线、`.`、`/`、`\`、`~`。所以 `./c/Users/…`、`foo/c/Users/…`、`/x/home/<名字>` 不换。
  - 例外是选项：紧跟在 `-` 加一个字母后面的照样换，盘符开头的写法跟在 `/` 加一个字母后面的也换。如 `-I/home/<名字>/include`、`-LC:\Users\<名字>\lib`、`/IC:\Users\<名字>\include`。
  - 第一版没有这个例外，这些都不换。原来不看边界，它们都换，所以第一版在这里是退步，自己试的时候发现，改了。
- **在原文上找**：一个正则，每个字母写成大小写两个字符的类，前后边界写成环视，直接在原文上 `sub`。
  - 不再用 `lower()`。Python 里只有 `İ`（U+0130）的小写会变长，变成两个字符。
  - 别的字符（`ß`、`ﬁ`）只在转大写时变长，原来也不影响位置。

## 3. 取舍

- **边界宁可少换**：后面跟着文件名里能有的字符，就当作另一个名字，不换。代价是 `C:\Users\<名字>.CORP` 这样的兄弟目录，用户名会原样发出。反过来多换，模型看到的文字就和实际运行的不一样，这正是 R30-1。
  - 2026-11-15 更正（修订 31 的复审 R31-2）：上面一句不准确。算结束的字符里，花括号、方括号、引号、空格、括号、逗号、冒号在文件名里都能有，有的在 shell 里还会接着名字往下写。实际的规定是第 2 节列出的那些字符，不是"文件名里不能有的字符"。修订 32 改了这几个字符，见 `docs/reports/M3a-rev31-review-fixes.md`。
- **前面的边界和选项**：`-I/c/Users/<名字>` 和 `foo/c/Users/<名字>`，前面都是字母，分不开。按"`-` 加一个字母"算选项，`foo-I/c/Users/<名字>` 这种写法也会被换，这种写法少见。
- **不换的写法照实写**：环境变量展开之后的值、URL 编码、拆开再拼起来的、8.3 短名、`\\localhost\c$\Users\<名字>` 这类共享路径、只差 Unicode 折叠的写法。规格、隐私文档写明这是尽力而为。
- **字符的规定不改**（R30-3）：不换行空格看起来是空格，在 shell 里却不是分隔符；私用区和未分配的码位，各处显示得不一样。所以照旧拒绝，只把文档写准确。
